# Personal Portfolio - Adem Bouzouita

A modern, interactive 3D motion personal portfolio showcasing projects, technical skills, and design aesthetics.

## Features

- **3D Kinetic Animation**: Interactive Three.js scene featuring animated wireframes and lighting.
- **Responsive Layout**: Designed with Tailwind CSS for mobile, tablet, and desktop viewports.
- **Dark Aesthetic**: Cyberpunk & neo-brutalist dark palette.
- **GitHub Pages Ready**: Self-contained static site ready to deploy instantly.

## Live Demo & GitHub Pages

To view locally:
Open `index.html` in your web browser.

To enable GitHub Pages:
1. Go to repository **Settings** on GitHub.
2. Under **Code and automation**, click **Pages**.
3. Under **Branch**, select `main` (or `master`) and `/ (root)`.
4. Click **Save**.
